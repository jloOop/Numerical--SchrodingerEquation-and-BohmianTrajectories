# Python-Scripts

## Solvers

**1. 3D Spinor Schrödinger Equation**

The script `solver_3D_spinor.py` implements the full 3D time evolution of a two-component (spinor) wave function using a Crank–Nicolson scheme on a Cartesian grid. It uses Dirichlet boundary conditions in the transverse directions, a spinor Robin absorbing boundary condition at the top, and a GPU-accelerated sparse linear solve (CuPy + GMRES with a simple diagonal preconditioner). The code constructs the harmonic-oscillator–like trapping potential in the transverse plane, prepares a localized spinor wave packet, advances it in time, and writes all relevant output to disk (coordinate grids, constants, `rho_prob_t*.npy` snapshots at fixed physical times, `prob_times.npy`, `total_probs.npy`, logs, etc.) in a format that is directly compatible with the post-processing scripts.

**2. Spin-dependent Bohmian Dynamics and Arrival time**

Within the same script, the numerically computed spinor solution is also used to set up and propagate Bohmian particle trajectories. Initial particle positions are sampled from the underlying probability density, and the dynamics are governed by the spin-dependent Bohmian velocity field associated with the evolving spinor wave function. The code is designed to track a large ensemble of particles, monitor first-arrival at the top absorbing plane, and (optionally) store a selected subset of trajectories and arrival times for detailed analysis and visualization.


 ## Loaders_Bohmian Arrival-Time & Trajectory Postprocessing:

6. The loader scripts such as  `Loader_To_SchrödingerEqn.py` is a dedicated loader and visualization pipeline for the data generated by the Solvers. It automatically finds the simulation directory, reads the saved arrays which were saved by the solvers, and computes global diagnostics such as total probability and probability loss rate as functions of time. It then generates mid-plane contour panels, XY slice plots, 3D high-density scatter views, and 3D iso-surface plots of the probability density for selected snapshot times (e.g. every Δτ = 0.1), saving them as PNGs in `Outputs_3D/`. Finally, it assembles these PNG sequences into GIFs for each plot family (midplanes, contour, scatter, iso-surfaces, slice bars), with a small © J & T label embedded directly into each figure as a copyrights.


The script `bohmian_arrivals_postproc.py` performs a unified analysis of Bohmian arrival times and trajectories using the data produced by `solver_3D_spinor.py`. It automatically detects whether it should use the full particle population (`bohm_t_hit.npy`, `bohm_arrived_mask.npy`) or only a stored subset (`bohm_t_hit_selected.npy`, `bohm_arrived_mask_selected.npy`), and reads the simulation setup from `constants.npz`.

What it computes and outputs:

- **Detector geometry & reference solution**  
  The detector plane position is reconstructed from the grid spacing and box size. On this basis, the script computes a quasi-free reference arrival-time distribution \(\Pi_{\rm qf}(\tau)\) via an integral representation of the propagator, providing a theoretical baseline for comparison with the interacting simulation.

- **Flux-based arrival statistics**  
  If available, the script loads `prob_times.npy` and `total_probs.npy`, reconstructs the probability loss rate \(-\mathrm{d}\|\psi_t\|^2/\mathrm{d}t\), and interprets it as an effective flux density through the absorber. It checks consistency by comparing the integral of this flux with the total probability drop over the simulation.

- **Histogram of Bohmian first-arrival times**  
  From the stored first-hit times (`bohm_t_hit*.npy` and masks), it extracts the first arrival at the detector for each particle, builds a normalized arrival-time histogram (per launched/loaded particle), and reports the detection fraction as well as the mean first-arrival time and its standard error.

- **Combined comparison plot**  
  All three notions of arrival statistics are shown in a single figure:
  1. The numerical flux curve \(-\mathrm{d}\|\psi_t\|^2/\mathrm{d}t\),  
  2. The quasi-free baseline \(\Pi_{\rm qf}(\tau)\),  
  3. The Bohmian first-arrival histogram (normalized per launched particle),  
  together with a vertical line indicating the mean Bohmian arrival time.  
  This figure is saved as `combined_arrival.png`.

- **Sample Bohmian trajectories (optional)**  
  If the file `bohmian_traj_selected.npy` (and optionally `bohm_times.npy`) is present, the script plots a small set of sample trajectories \(z(t)\) from the selected particles, overlaying the detector plane. This diagnostic plot is saved as `sample_traj_z_vs_t.png`.

In summary, this postprocessing script ties together probability loss, theoretical arrival distributions, and Bohmian first-hit statistics into one coherent analysis and visualization pipeline.
