1. # Solvers:
2.**Schrödinger Eqn**
3.   The script `solver_3D_spinor.py` implements the full 3D spinor Schrödinger time evolution using a Crank–Nicolson scheme on a Cartesian grid. It includes Dirichlet boundary conditions in the transverse directions, a spinor Robin absorbing boundary condition at the top, and a GPU-accelerated sparse linear solve (CuPy + GMRES). The code sets up the initial spinor wave packet, advances it in time, and writes all relevant data to disk (coordinate grids, constants, `rho_prob_t*.npy`, `prob_times.npy`, `total_probs.npy`, etc.) for later analysis, along with Bohmian trajectory data in selected runs.

4. # Loaders:
5.
6. The loader scripts such as  `Loader_To_SchrödingerEqn.py` is a dedicated loader and visualization pipeline for the data generated by the Solvers. It automatically finds the simulation directory, reads the saved arrays which were saved by the solvers, and computes global diagnostics such as total probability and probability loss rate as functions of time. It then generates mid-plane contour panels, XY slice plots, 3D high-density scatter views, and 3D iso-surface plots of the probability density for selected snapshot times (e.g. every Δτ = 0.1), saving them as PNGs in `Outputs_3D/`. Finally, it assembles these PNG sequences into GIFs for each plot family (midplanes, contour, scatter, iso-surfaces, slice bars), with a small © J & T label embedded directly into each figure as a copyrights.
