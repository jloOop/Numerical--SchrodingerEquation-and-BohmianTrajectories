
# 1D simulations

## What is here

CPU-friendly one-dimensional Schrödinger detector-model material, including a solver/post-processing script and selected outputs such as GIFs and trajectory plots.

## What to open first

- `1D/PythonScripts/README.md`
- `1D/Outputs/README.md`

## What is reproducible

The 1D workflow is the most suitable candidate for a minimal local example. Before running, inspect the script for historical hard-coded output paths and replace them with a relative path such as `outputs/1d/`.
