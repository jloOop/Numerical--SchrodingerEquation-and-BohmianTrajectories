## Bohmian Trajectories

 [Download (Bohmian_Trajectories_4D.zip)](https://github.com/jloOop/Numerical--SchrodingerEquation-and-BohmianTrajectories/releases/download/v1.0-3D-paper/Bohmian_Trajectories_4D.zip)  
This archive contains Bohmian-trajectory simulations for multiple parameter settings. Each simulation folder includes the data, analysis scripts, and a record of the run parameters.

(i) This collection contains data and analysis scripts for **3D Bohmian trajectories evolved in time** (i.e., 3 spatial dimensions + 1 time dimension). For the physics and mathematical details, see our paper [REF].

(ii) In folder names, the tag `+C` indicates simulations with **spinor absorbing boundary conditions**. Folders without `C` use **scalar absorbing boundary conditions** only.

(iii) Each simulation folder includes a `stdout.txt` file listing all relevant solver parameters and diagnostic output.

(iv) The transverse box sizes `Lx` and `Ly` (x–y plane) are chosen as functions of the harmonic-oscillator frequency `ω` to ensure the spatial discretization resolves the wavefunction adequately and avoids probability loss in the tails.
